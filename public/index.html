Pesquisa aprofundada na web

Uma tarefa agendada (de hora em hora) pega os pedidos, pesquisa na web dados atuais do estado e do segmento — distribuição de classes, emprego, crédito e inadimplência, concorrência, tendências de busca — e grava aqui um relatório com as fontes.

Fontes e atualização

Uma tarefa agendada confere todo dia 5 os sites dos órgãos responsáveis. Quando o IBGE divulga uma nova PNAD de rendimento, o GeoVenda recalibra a renda de todos os estados sozinho (junto com o salário mínimo do mesmo ano). Para as demais bases, a linha passa a mostrar “nova versão disponível” com a data de divulgação.
